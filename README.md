# 📦 Retail Supply Chain 360-Degree Analytics Dashboard

A comprehensive, interactive web application built with **Python**, **Streamlit**, and **Plotly** to provide a 360-degree view of retail store operations, inventory tracking, logistics performance, and supplier metrics.

---

## 🚀 Key Features

* **Executive Performance KPIs:** Real-time tracking of estimated revenue, On-Time In-Full (OTIF) delivery rate, average supplier lead time, defect rate, and stockout risk alerts.
* **Operational Overview:** 
  * Demand forecasting vs. actual sales trends over time.
  * Stock volume analysis broken down by product categories (Electronics, Apparel, Home Goods, Groceries, Beauty).
* **Supplier & Logistics Evaluation:** Scatter plotting vendor lead times against defect rates, weighted by OTIF delivery performance.
* **Store-Level Deep Dive & AI Insights:** Filterable data grids showing store-level metrics alongside automated supply chain bottleneck detection and actionable recommendations.

---

## 🛠️ Tech Stack

* **Frontend & UI:** Streamlit
* **Data Processing:** Pandas, NumPy
* **Data Visualization:** Plotly Express
